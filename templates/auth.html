Google OAuth 2.0 блокує авторизацію з file://. Щоб увійти через Google:

  1. Запустіть Live Server у VS Code або виконайте в терміналі: python -m http.server 5500
  2. Відкрийте у браузері: http://localhost:5500/templates/auth.html
